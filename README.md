# bukhorizainun.github.io

Personal portfolio of Mochamad Bukhori Zainun, built as an infinite canvas of slides.

- Intro: a particle model of a buoyant jet (the flow from my master's thesis) that settles into my name.
- Move: drag, scroll, pinch or Ctrl + scroll to zoom, arrow keys between slides, `O` for the overview, `Ctrl K` to search.
- Tools: highlighter and sticky notes, stored only in the visitor's browser.
- Narrated tour: the browser's speech synthesis reads each slide, with captions.
- Phones and narrow windows get a plain vertical layout.

Plain HTML, CSS and JavaScript. No build step.

Run locally:

```
python -m http.server 8000
```
